# Security Policy

## Supported Versions

`ozsh` is pre-1.0. Security fixes are provided for the latest tagged release
and the current `main` branch.

## Reporting A Vulnerability

Use GitHub private vulnerability reporting for this repository. Do not open a
public issue containing exploit details, credentials, private paths, or logs.

Include the affected version, operating environment, reproduction steps, and
the expected impact. Reports will be acknowledged as soon as maintainers are
available; no fixed response SLA is promised for this pre-1.0 project.

Never include an unredacted `.zshrc`, `config.toml`, plugin URL containing
credentials, or `ozsh.log` in a report.
